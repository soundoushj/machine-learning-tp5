# TP5 – Feature Selection

This practical session explores feature selection techniques using the **Breast Cancer Wisconsin (Diagnostic)** dataset.

### Topics Covered
- Filter methods: Variance Threshold, Correlation, ANOVA and Mutual Information.
- Wrapper methods: Forward Selection, Backward Elimination, RFE and RFECV.
- Noise feature detection and data leakage.
- Performance evaluation and feature comparison.

### Technologies
Python, NumPy, Pandas, Matplotlib, Seaborn and Scikit-learn.
